# Aula: Bases de Dados de Emprego no Brasil

Este projeto contem 3 apresentacoes em **Quarto + RevealJS** sobre fontes oficiais de dados de trabalho e emprego.

Temas das apresentacoes:

- CAGED
- RAIS
- PNAD Continua

## Requisitos

Instalar Quarto:

https://quarto.org

Bibliotecas Python para os exemplos (BigQuery + analise de dados):

No seu ambiente proprio, execute na pasta da aula:

pip install -r requirements.txt

## Rodar apresentacoes

No terminal da pasta:

quarto preview

ou

quarto render

## Estrutura

slides/
    aula_caged.qmd
    aula_rais.qmd
    aula_pnad_continua.qmd
