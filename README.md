# Café com dados (cafe-com-dados)
Repositório com códigos utilizados no alinhamento de conhecimentos relacionados a programação, estatística e ciência de dados, dos servidores lotados na CGID.

Sumário:
1. Mapeamento de NCM para Cnae

## Aulas

1. Bases de dados de emprego
	- Pasta: `aulas/bases de dados de emprego`
	- Conteudo: CAGED, PNAD Continua, RAIS e materiais de apoio
2. Programacao orientada a objetos
	- Pasta: `aulas/programacao orientada a objetos`
	- Conteudo: conceitos de POO com exemplos aplicados ao comercio exterior
3. GitFlow e controle de versao
	- Pasta: `aulas/gitflow`
	- Conteudo: filosofia GitFlow, comandos principais, branches, merge request, comparacao VS Code e RStudio/Posit
